# OmniDesk – Frontend

OmniDesk is a customer portal frontend application developed using React. It provides a user interface for managing customer information and interacting with a Spring Boot backend through REST APIs.

## 🚀 Features

- Create and manage customer records.
- View customer details from the backend.
- Perform customer CRUD operations supported by the backend APIs.
- Integrate with REST APIs using Axios.
- Display customer data through a React-based interface.
- Communicate with a MySQL-backed Spring Boot application.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Axios
- React Router
- Bootstrap
